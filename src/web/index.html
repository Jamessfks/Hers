Setup

Gemini API key

This is the one thing she cannot work without. It is checked with Google before it is saved, then written to her key file — .env beside the clone if you run her from a terminal, or inside her own folder if you installed the application. Either way it stays on this machine and is never sent back to this page.

Get one at aistudio.google.com/apikey.

Reach her on Telegram

The same companion, on your phone — one memory, one mood. Make a bot with @BotFather, send it /newbot, and paste the token it gives you. It is checked with Telegram before it is saved, then written to the same key file as the Gemini key and kept on this machine.

One step left, and only you can do it: open the chat and press Start. A bot is not allowed to message first, and nothing in Telegram tells it which chat is yours — so the first chat to speak is the one she is locked to, and it is written down for good.
